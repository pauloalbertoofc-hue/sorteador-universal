Perguntas frequentes

Preciso de uma moeda física?

Não. O sorteio é realizado digitalmente entre as duas opções.

Posso trocar Cara e Coroa por outras escolhas?

Sim. Edite os textos no campo de opções antes de sortear.

O resultado é sempre o mesmo?

Não. Cada sorteio é realizado novamente e pode produzir qualquer uma das duas opções.

Este modelo é indicado para decisões simples e brincadeiras, não para decisões de alto risco.
